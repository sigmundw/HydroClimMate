# WRF-Urban sources

Checked: 2026-09-16. Scope: official rolling WRF Users' Guide, not a frozen release. Lab WRF/WPS version and urban option: unknown. No WRF executable was run.

## W1

[WRF Physics](https://www2.mmm.ucar.edu/wrf/site/users_guide/physics.html): retrieved; Land Surface Model → Urban Effects and LSM Tables. Supports UCM/BEP/BEM distinctions, configuration dependencies and urban input cautions. No current compatibility/default table is copied as a universal rule.

## W2

[WPS](https://www2.mmm.ucar.edu/wrf/site/users_guide/wps.html): retrieved; overview and geographic/meteorological preprocessing structure. Used for stage separation, not every dataset recipe.

## W3

[Running WRF](https://www2.mmm.ucar.edu/wrf/site/users_guide/running_wrf.html): retrieved; real-data execution and restart workflow. Exact commands/options require the target version.

## W4

[WRF Output](https://www2.mmm.ucar.edu/wrf/site/users_guide/output.html): retrieved; history/output customization. No claim that all diagnostics are available in every build.

## W5

[Output variables](https://www2.mmm.ucar.edu/wrf/site/users_guide/output_variables.html): retrieved; dimensions, units and descriptions in the example header, including staggering, perturbation/base fields and accumulated precipitation. Field names are not a cross-version API.

## Navigation and gaps

[Historical guides](https://www2.mmm.ucar.edu/wrf/users/docs/user_guide_v4/contents.html) provide the version-selection route; [NCAR urban model](https://ral.ucar.edu/model/urban-canopy-model) is a product overview. Exact urban diagnostics, custom lab tables and option combinations need the matching code/configuration. This is an original summary, not a copy of those guides.
