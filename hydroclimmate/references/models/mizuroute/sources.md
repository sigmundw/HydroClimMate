# mizuRoute sources

Checked: 2026-09-16. Scope: standalone basics in the floating `stable` documentation; no numbered release or lab coupling is inferred. No compilation or routing run was performed.

## M1

[ESCOMP/mizuRoute](https://github.com/ESCOMP/mizuRoute): retrieved via the redirect from NCAR/mizuRoute; current repository identity. A repository move is not evidence that a particular older configuration is compatible with its present code.

## M2

[Input files](https://mizuroute.readthedocs.io/en/stable/users_guide/Input_files.html): retrieved; river data, three runoff spatial representations and remapping requirements. The page contains incomplete advanced-feature navigation; only basic routing is distilled.

## M3

[Hillslope routing](https://mizuroute.readthedocs.io/en/stable/users_guide/Hill.html): retrieved; HRU area conversion and optional hillslope response. Supports avoiding duplicate area conversion/delay, not a universal coupled-interface contract.

## M4

[River routing](https://mizuroute.readthedocs.io/en/stable/users_guide/Riv.html): retrieved; method choices, channel parameters and unrouted upstream accumulation. No method/default is selected on behalf of the researcher.

## M5

[Control file](https://mizuroute.readthedocs.io/en/stable/users_guide/Control_file.html): retrieved; basic configuration and examples. Exact keys and unit conversions require the actual executable/control file. Example paths are not lab paths.

## M6

[Output files](https://mizuroute.readthedocs.io/en/stable/users_guide/Output_files.html): retrieved; output-stage distinctions and IDs. No full variable catalog or timestamp rule is asserted across versions.

## Limits

Detailed lake/reservoir schemes, water management, solute transport, calibration recipes and CTSM coupling APIs are outside coverage. This is original explanatory text and diagnostic guidance, not a redistributed manual or a ready-made VIC adapter.
